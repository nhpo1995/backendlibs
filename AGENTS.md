# Backend Service

- FE chính hiện dùng React + TypeScript + Vite trong `frontend/src/`. Chạy `npm run dev` ở cổng 8765, `npm run build` xuất `dist/`, `npm run preview` ở cổng 5174. Python chỉ biên soạn/xuất nội dung, không phục vụ FE. Không dùng file:///server Python để kiểm chứng React.
- Trang nhóm riêng chỉ hiện bài của nhóm được chọn. Giữ route canonical/alias/deep link và base path triển khai. CodeMirror phải cleanup theo lifecycle React; giữ keys localStorage cũ và tránh ghi đè nháp từ tab chưa sửa. Backend Node.js/TypeScript và đăng nhập chưa triển khai.
- Giáo trình Spring hiện được tổ chức theo kiến thức, không theo buổi video. Được tách/gộp nguồn để giải thích cơ chế và đặt bài tập coding phù hợp. Slug bài mới dùng tên chủ đề; các thư mục `buoi-*` chỉ còn là alias và nơi giữ demo cũ.
- Nguồn biên soạn nằm ở `content/springboot/course.json`, `content/springboot/*.html` và `content/springboot/extensions/`. Dùng `python scripts/build_site.py` để sinh trang; không sửa trực tiếp HTML đầu ra. Tham khảo bài Core tại `content/springboot/ioc-container.html`, Web tại `content/springboot/dto-contracts.html` và project ở `content/practice.html`; trang Buổi 1 cũ không còn là template bài đọc.
- Mỗi bài cần tách biệt bài tập tự viết implementation với thao tác nghiệm thu trên demo hoàn chỉnh. Editor web lưu/sửa/tải snippet và đối chiếu với lời giải qua nút Kiểm tra (bỏ qua định dạng/chú thích, giữ literal/cấu trúc); không tự đánh dấu hoàn thành. Chỉ tuyên bố chạy/chấm Java khi có môi trường thực thi thật. Bài chỉ có checklist dùng đối chiếu thủ công. Đăng nhập bảo vệ bài đọc để giai đoạn sau.
- Dự án là website tĩnh tự học backend. Mỗi khóa có trang danh mục trong `lessons/<khoa>/index.html`. Mỗi bài có `index.html` riêng và có thể kèm demo chạy độc lập. Tài nguyên web dùng chung nằm ở `assets/`. Dùng đường dẫn tương đối để trang mở được từ file và trên GitHub Pages.
- Khi nhận link video, thư mục nguồn hoặc yêu cầu tiếp tục một bài, dùng skill `$backend-lesson`. Nếu bộ chọn skill chưa hiển thị, đọc [.agents/skills/backend-lesson/SKILL.md](.agents/skills/backend-lesson/SKILL.md). Bắt đầu từ [danh mục khóa](lessons/COURSES.md) để xác định khóa, bài và trạng thái.
- Trong project này, một link video hoặc thư mục gửi riêng được hiểu là nguồn để đưa vào quy trình biên soạn. Phạm vi cụ thể đi theo yêu cầu kèm theo và quy tắc chọn bài trong skill.
- Viết bài bằng tiếng Việt cho người chưa biết video tồn tại. Bài đọc phải tự cung cấp bối cảnh, giải thích cơ chế và hướng dẫn kiểm chứng kết quả. Mốc video là tài liệu xem lại. Áp dụng bước kiểm tra bài đọc độc lập trong `backend-lesson` trước khi đánh dấu hoàn tất.
